# ML Universe v0.9 — система визуального обучения

## Зачем переработаны графики

Вместо одинаковых карточек «график №1—№4» лаборатория выстраивает рассказ: **вопрос → основная визуализация → второстепенные доказательства → математические значения**. Необязательные графики в длинных лабораториях раскрываются отдельно. Интерфейс сохраняет минималистичные светлую и тёмную темы.

## Законы визуализации

1. **Один фокус.** Первый график — крупный, остальные меньше и с объяснением их назначения.
2. **Один язык цвета.** Данные и исходные наблюдения — бирюзовые, модель и траектория — тёплые оранжевые оттенки, сравниваемые методы — различимые дополнительные цвета. Дискретные классы не кодируются непрерывной цветовой шкалой.
3. **Нормальные подписи.** Название графика не дублируется внутри Plotly. Оси имеют человеческие названия и достаточные поля; пустые/длинные названия не перекрывают значения. Рядом с графиком есть короткая инструкция.
4. **Компактное управление.** Только «приблизить», «отдалить», «сброс». Для 3D доступны вращение мышью и масштаб; для регрессии 2D/3D — разные представления одной поверхности, а не два независимых виджета.
5. **Объяснение на основе данных.** Состояние, траектории, вероятности и градиенты вычисляются сервером Python. Визуальный слой не подменяет их случайными числами. В линейной регрессии показывается реальное изменение loss относительно исходной точки.
6. **Значение вместо украшения.** 2×2 и небольшие матрицы сохраняют квадратные ячейки. Длинные кандидаты разбиения дерева превращаются в горизонтальный рейтинг. Поверхности имеют последовательную шкалу; знакопеременные ядра — расходящуюся.
7. **Спокойная плотность.** Одновременно до трёх графиков, остальные за «Ещё графики» там, где это применимо. Сохраняем математический инспектор, модульные параметры и историю оптимизации.
8. **Нет обмана.** Если браузер не поддерживает WebGL, 3D-поверхность отображается двумерными линиями уровня. Пояснения различают игрушечные вычисления, реальные обученные модели и проекции.

## Что нужно увидеть в каждой из 29 лабораторий

| Раздел | Главный смысл | На что смотреть |
|---|---|---|
| Линейная регрессия | Прогноз и остаточная ошибка | Точки, линия, затем траектория в 2D/3D и ход loss |
| Функции потерь | Разница штрафа и его производной | Рост штрафа с остатком и наклон кривой |
| Регуляризация | Поведение весов при росте α | Пути коэффициентов и число ненулевых весов |
| Арена оптимизаторов | Сравнение при одинаковых начальных условиях | Траектории, loss по шагам и поверхность |
| Learning Rate | Изменение шага | Форма графика расписания |
| Hyperparameter Sweep | Сравнение сетки опытов | Цвет результата при одинаковом бюджете |
| Классификаторы | Граница решений | Дискретные классы, точки, ошибки, ROC/PR |
| Decision Tree | Причина разбиения | Границы и упорядоченный выигрыш split |
| Ансамбли | Сложность разделяющей области | Область решения и матрица ошибок |
| K-Means | Движение центроидов | Положение центров и уменьшение inertia |
| Один нейрон | Взвешенная сумма → активация | Маркер на кривой и вклады входов |
| Activation Explorer | Чувствительность активаций | Значения и производные на одинаковом интервале |
| MLP / XOR | Нелинейность обученной сети | Поле решений и train loss |
| Градиенты и Dropout | Передача сигнала по глубине | Масштаб активаций и норма градиента |
| CNN | Устройство свёртки | Вход, ядро, выход и receptive field |
| RNN | Состояние после каждого токена | Hidden states и их нормы |
| Text Preprocessing / TF-IDF | Числовое представление документов | Термин-документ и cosine similarity |
| BPE | Слияния токенов | Изменение числа токенов |
| Text Classification | Словарь → вероятности | Вероятности классов и обучающие частоты |
| Word Embeddings | Связи контекстов | PPMI и аккуратно интерпретируемая 2D-проекция |
| Attention Q/K/V | Вес внимания | Оси запросов/ключей и сумма строки после softmax |
| Multi-Head Attention | Разные проекции | Матрицы отдельных голов и итоговое представление |
| Decoding / Sampling | Изменение распределения | Исходные и отфильтрованные вероятности |
| RAG Retrieval | Поиск фрагментов | Cosine similarity документов, не генерация ответа |
| Multi-Armed Bandit | Исследование и эксплуатация | Истинные/оценённые вероятности и regret |
| Gradient / Hessian | Геометрия функции | Касательная, градиент и линии уровня |
| Векторы и матрицы | Геометрический смысл операций | Вектора и трансформация |
| Нормы | Геометрия ограничений | Формы L1/L2/L∞ |
| Entropy / KL / JS | Различие распределений | Сравнение вероятностей и метрик |

## Как проверять

- `node --check ml_universe/static/visual_story.js`
- `node scripts/visual_contract.mjs` — проверка геометрии и оформления без браузера.
- `python -m pytest -q` — существующие математические и API-тесты.
- `./scripts/run_linux.sh` — руками проверить: переключение 2D/3D, темы, увеличение/сброс, K-Means, дерево, Attention, длинные подписи.
- GitHub Actions выполняет Python 3.11/3.12, Node-контракты и API smoke test после PR.

Сами экспериментальные данные и API сохранены. Изменена только организация их отображения; новые алгоритмы здесь намеренно не добавлялись.
