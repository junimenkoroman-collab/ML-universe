# GitHub + Linux: ML Universe

## Рекомендуемый процесс

- Основная ОС — Linux. Запуск через браузер + локальный Python API.
- Репозиторий GitHub хранит исходники, версии и задачи.
- При каждом push/PR GitHub Actions запускает Linux-тесты.
- Workflow Windows сохранён для будущего; запускать его необязательно.
- Ветки: `main` (проверенный код), `feature/...` (новая функция), `fix/...` (исправление).
- Сначала задача → изменения → `pytest` → Pull Request → GitHub CI → merge.

## Первый запуск на Linux

```bash
sudo apt install python3 python3-venv python3-pip  # Debian/Ubuntu (пример)
./scripts/run_linux.sh
```

Для остальных дистрибутивов — установить Python 3.11+ и пакет venv через штатный менеджер пакетов.
Скрипт автоматически создаст `.venv`, установит Python-зависимости и откроет браузер с локальным приложением.
Для запуска без открытия браузера вручную:

```bash
.venv/bin/python -m ml_universe --no-open --port 8765
```

Затем открыть `http://127.0.0.1:8765/` локально.

### Проверка

```bash
.venv/bin/python -m pip install pytest
./scripts/test_linux.sh
```

## Передача в GitHub

Создайте (или клонируйте) репозиторий `junimenkoroman-collab/ML-universe`. Скопируйте **содержимое** этой папки в корень клона, сохранив `.github` и `.gitignore`.

```bash
git add .
git commit -m 'Import ML Universe and add Linux CI'
git push -u origin main
```

Если репозиторий уже содержит историю, **клонируйте его сначала**, а не запускайте новый `git init` поверх существующих файлов. Если в ветке есть другие изменения, согласуйте их перед копированием.

### Авторизация

Выполняйте `gh auth login` или вход в Git Credential Manager самостоятельно. Не передавайте пароли, access tokens или приватные SSH-ключи в чат.

## Развёртывание для себя на удалённом Linux

**Сейчас API предназначен только для локального доверенного пользователя.** Состояние эксперимента хранится глобально, полноценной авторизации нет. Не открывайте приложение напрямую на `0.0.0.0` или через публичный reverse proxy.

Безопасный промежуточный вариант — SSH-туннель к loopback-инстансу:

На сервере:

```bash
./scripts/run_linux.sh --no-open --port 8765
```

На своём компьютере:

```bash
ssh -L 8765:127.0.0.1:8765 USER@SERVER
```

Откройте локально `http://127.0.0.1:8765/`. Серверный порт наружу открывать не нужно. Это конфигурация для одного доверенного пользователя. Перед публичной публикацией необходимо реализовать сессии, аутентификацию, изоляцию данных, лимиты вычислений и безопасность запросов.

## Сборка на Linux (необязательно)

```bash
bash scripts/build_linux.sh
```

Сборка PyInstaller под Linux создаёт Linux-дистрибутив, не Windows `.exe`. Скрипты Windows и CI Windows оставлены в репозитории без изменений.
