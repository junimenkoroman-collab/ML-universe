# Как учиться в ML Universe — практические маршруты

## 1. Линейная регрессия за 20 минут

Выбери **«Линейная регрессия»**. В правой панели поставь `w=-2`, `b=-2`, посмотри на residuals и текущее значение loss. Затем на timeline несколько раз нажми **▶|**: сопоставь положение линии на scatter plot, точку на loss surface и изменение градиента в инспекторе. Уменьши/увеличь `Learning rate η` и повтори эксперимент кнопкой **↺**.

Для **GD** выбери `Optimizer=SGD` и `Выбор batch=GD · полный датасет`. Для стохастического варианта `Выбор batch=SGD · один пример`; для Mini-batch — `Mini-batch SGD`. Алгоритм оптимизатора и режим выборки batch — разные настройки.

Затем переключи `Loss` с MSE на MAE/Huber/Smooth L1/Quantile и оцени влияние выбросов. Выбери `L1`, `L2`, `Elastic Net` и двигай lambda. При `Weighted MSE` выбирай режим весов наблюдений. Bias по умолчанию не штрафуется.

## 2. Оптимизация и регуляризация

Открой **«Арена оптимизаторов»**: выбери Rosenbrock или Himmelblau, сравни траектории, затем переключись на `Projected GD vs GD` и измени радиус. Поверхность 3D отображается при WebGL; иначе автоматически появится 2D contour plot.

Открой **«Регуляризация»** и сравни, как Ridge и Lasso уменьшают коэффициенты при росте alpha. В **«Hyperparameter Sweep»** построится 5×5 таблица итоговых значений objective для разных `lr/λ` на одной задаче. Этот эксперимент **не выбирает лучшие гиперпараметры для обобщения**: разные λ меняют сам objective.

## 3. Классификация и K-Means

В **«Классификаторы»** меняй Logistic Regression, kernel/linear SVM, kNN и Naive Bayes. Наблюдай границы решений, ROC/PR и метрики при изменении threshold. Для **Softmax Regression** используется отдельный 3-классовый набор Gaussian Blobs.

В **«Decision Tree»** меняй max depth, criterion и min leaf. Смотри таблицу split-кандидатов. В **«Random Forest / Boosting»** изучай границы ансамбля. Метрики на этих страницах рассчитаны на обучающих данных — это инструмент для изучения механизма, а не строгое внешнее сравнение качества.

В **K-Means** меняй `k`, инициализацию и число итераций. На scatter plot видно реальные траектории центроидов; на другом графике — inertia.

## 4. Нейрон → MLP → RNN

В **«Один нейрон»** меняй x, w, bias и activation. Посмотри `z=w·x+b`, выход `f(z)` и производные.

В **«MLP / XOR»** запусти обучение XOR и наблюдай нелинейную поверхность вероятностей, BCE и параметры сети. В деталях есть сравнение аналитического и численного `dL/dW1[0,0]`.

В **«Градиенты и Dropout»** меняй init (`zeros / Xavier / He / large`), глубину и keep probability. Графики показывают прямые активации и обратные производные *необученной* ReLU-сети.

В **«CNN / Receptive Field»** меняй kernel, stride и padding. Сравни входную матрицу, значения 3×3 и итоговую feature map.

В **«RNN»** вводи слова и наблюдай скрытые векторы для каждого шага. Это Elman RNN с фиксированными случайными матрицами, не языковая модель.

## 5. NLP: от токенов к Attention и RAG

Начни с **«Препроцессинг / TF-IDF»**, измени корпус и посмотри матрицу частот. Далее **BPE**: увеличивай число merge и изучай таблицу слияний. В **Word Embeddings** изучай co-occurrence, PPMI и 2D-проекцию распределительных векторов.

В **Q/K/V · Attention** включи causal mask и наблюдай, что запрещённые веса становятся нулевыми, а строки attention суммируются в 1. В **Multi-Head Attention** увеличь число голов и сравни их матрицы.

В **Decoding / Sampling** начни с greedy, затем выбери sampling и двигай temperature/top-K/top-P. Это честные вероятности по фиксированным учебным logits, а не реальная LLM.

В **RAG · Retrieval** вводи документы, разделённые `|`, и задавай вопрос. Лаборатория покажет TF-IDF cosine similarity и выбранные top-k фрагменты. Этап **генерации текста LLM не моделируется**.

## 6. Multi-Armed Bandit

Меняй epsilon между 0 (всегда exploit текущую лучшую ручку) и 1 (случайные действия). Сравни число pull, reward и pseudo-regret. При одинаковом seed симуляция воспроизводима.

## Интерфейс и кнопки

- **Светлая/тёмная тема** — кнопка ☼/☾ в шапке; выбор запоминается при разрешённом localStorage.
- **«Применить настройки»** — пересчитать текущий экран; в регрессии начинает новый run с указанными параметрами.
- **CSV / Сохранить / Открыть** — относятся к главной линейной регрессии; другие экраны сейчас не поддерживают export run.
- **History timeline** — только для линейной регрессии: Play/Pause, Back, Step, +25, +100, Seek.
- **Space** — Play/Pause вне полей ввода, **Esc** — закрыть помощь/остановить воспроизведение.

## Обновление кода и CI

При первом запуске `git clone`, затем `./scripts/run_linux.sh`. Чтобы получить наши последующие изменения: `git pull --ff-only` и снова запуск. Тесты локально: `./scripts/test_linux.sh`. GitHub Actions автоматически выполняет Python тесты и проверку синтаксиса JS на push/PR, без твоего участия.
