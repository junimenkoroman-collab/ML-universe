# Принципы визуализации ML Universe v0.9

## Цель
Пользователь должен без чтения кода ответить на три вопроса:
1. Что именно на графике?
2. Почему этот график появился здесь?
3. Что изменится, если я переключу один параметр?

## Основа
Идея заимствована из педагогического подхода TensorFlow Playground и Distill: научный объект важнее элементов управления. Визуальные принципы IBM и Observable применены к подписыванию осей, небольшому количеству цветов и интерактивному просмотру точных значений.

## Новая анатомия экрана
- Вопрос лаборатории и короткая инструкция «с чего начать».
- Главный график на всю ширину области эксперимента.
- 1–2 небольших графика, показывающих причину или развитие результата.
- Если расчётов больше трёх: дополнительные графики раскрываются отдельно.
- Подробные таблицы остаются в математическом инспекторе.
- Параметры по-прежнему подключаются модульно.

## Семантика
- Оранжевая линия: модель или путь обучения.
- Бирюзовые точки: наблюдения или базовый сигнал.
- Классы: фиксированные оттенки разных категорий, а не непрерывный градиент.
- Heatmap: последовательная светло-тёмная шкала, если значения упорядочены.
- Оси всегда подписаны исходными математическими величинами, единицы/названия не заменяются декоративными фразами.
- Для матриц малого размера клетки по возможности квадратные.
- Если категории длинные, столбики должны быть горизонтальными.
- 3D график не должен быть обязательным: нужен 2D fallback при отсутствии WebGL.

## Кнопки
Только приблизить, отдалить и сбросить масштаб. Для 3D переключение камеры использует те же три действия. Не добавляем скриншоты, выделение lasso, экспорт или скрытие кривых через лишние панели.

## Регрессия
Три карточки вместо четырёх: наблюдения и линия, одна карточка «пространство весов» с переключателем 2D/3D, история ошибки. Все данные настоящие и синхронизированы с одним состоянием.

## Проверка
`node --check ml_universe/static/visual_story.js`, `python -m pytest -q`, GitHub Actions Linux 3.11/3.12.
Визуальный smoke при возможности: 1440/900 и 390/844, светлая/тёмная тема, прямое увеличение масштаба, смена 2D/3D, переключение лабораторий, отсутствие ошибок JavaScript.
