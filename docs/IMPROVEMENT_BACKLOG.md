# ML Universe — приоритеты следующего улучшения

Только внутри согласованного ML → DL → NLP scope:

1. Пошаговая визуализация вычисления loss и batch gradient для каждой выбранной точки линейной регрессии.
2. Визуальный расчет отдельных SGD/Momentum/RMSProp/AdamW моментов и обновлений по двум весам.
3. Более явный переключатель и объяснение train/validation метрик классификации (сейчас показаны train metrics).
4. Дерево CART с интерактивными узлами, навигацией и pruning.
5. Пошаговый калькулятор MLP backprop с Jacobian и проверкой матричных размеров.
6. CNN receptive field для нескольких слоёв и визуализация прохождения патча.
7. RNN BPTT на короткой последовательности (в текущем релизе только forward).
8. Attention mask editing и интерактивные Q/K/V матрицы без больших моделей.
9. Улучшенная PPMI и subword-токенизация для русского текста.
10. Опциональный локальный LLM-инференс для финальной стадии RAG — отдельно, с явной установкой веса и без сетевой зависимости базового UI.
11. Нормальный визуальный CI (Playwright+Chromium) и проверка в пользовательском Linux окружении.

Из этой ветки сознательно исключены RL Gridworld, GAN, diffusion, time series, Graph ML, MCMC, fairness, recommendations и прочие темы вне личной программы.
