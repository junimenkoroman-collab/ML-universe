Как пользоваться ML Universe

Слева выбирайте темы в последовательности ML → Deep Learning → NLP. Справа меняйте параметры и нажимайте «Применить». Результаты показываются на графиках и в математическом инспекторе.

В линейной регрессии попробуйте менять w и b, затем нажимать «Шаг», двигать timeline и сравнивать оптимизаторы. Каждый график строится по вычислениям, а не по демонстрационной картинке.

Тёмная и светлая темы переключаются в шапке. Ctrl/Cmd не требуется. Для обновления проекта на Linux используйте git pull и ./scripts/run_linux.sh.

Режимы attention, RNN и RAG показывают учебную математику, не работу предобученной LLM.
