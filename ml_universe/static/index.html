Как пользоваться ML Universe

Слева выбирайте темы в последовательности ML → Deep Learning → NLP. Справа доступны только основные параметры. Для остальных нажмите «＋ Добавить блок»: например, подключите оптимизатор, функцию потерь или регуляризацию. Неиспользуемые блоки можно убрать кнопкой ×. Результаты показываются на графиках и в математическом инспекторе.

В линейной регрессии по умолчанию используется полный градиентный спуск с MSE. Изменяйте w и b, затем используйте кнопки истории обучения: шаг назад, воспроизведение, шаг вперёд и +25. Для сравнения алгоритмов откройте отдельную «Арену оптимизаторов». Для формул раскройте «Математический инспектор» под графиками.

На графике доступны увеличение, уменьшение и сброс масштаба; приближение колёсиком и двойной щелчок для сброса. Тёмная и светлая темы переключаются в шапке. Для обновления проекта на Linux используйте git pull и ./scripts/run_linux.sh.

Режимы attention, RNN и RAG показывают учебную математику, не работу предобученной LLM.
